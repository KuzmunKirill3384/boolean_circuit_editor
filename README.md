# Редактор булевых схем

Приложение для создания, редактирования и анализа булевых схем из логических элементов `AND`, `OR`, `XOR`, `EQUAL`. Поддерживает таблицу истинности, упрощение схемы, полиномиальное представление и сохранение в XML.

## Возможности

- Создание и редактирование схемы: добавление элементов, соединение, перемещение.
- Валидация: запрет циклов, контроль числа входов/выходов.
- Undo/Redo для всех действий.
- Таблица истинности для всей схемы.
- Упрощение схемы при фиксированных входах с оценкой удаляемых элементов (логика реализована, интерфейс дорабатывается).
- Полиномиальное представление элементов (логика реализована, интерфейс дорабатывается).
- Настройка цветов, размеров, шрифтов.
- Сохранение и загрузка схем в XML.

## Стек

- `Python 3.10+`
- `PyQt6` GUI
- `pytest` для тестирования
- `xml.etree.ElementTree` или `lxml` для XML

## Архитектурные паттерны

- **Composite**: модель схемы и иерархия элементов
- **Command**: операции редактирования с поддержкой отмены
- **Visitor**: обход модели при do/undo и вычислениях
- **Factory**: создание команд
- **Builder**: загрузка и сохранение XML
