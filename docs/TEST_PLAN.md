# План тестирования

Документ фиксирует стратегию тестирования редактора булевых схем.  
Ответственный: **Боос Д. А.**

## Цели

- проверить корректность модели схемы и операций над ней;
- проверить устойчивость к некорректным соединениям (циклы, двойные подключения);
- проверить работу undo/redo;
- проверить загрузку и сохранение XML (корректные и некорректные файлы);
- проверить вычислительные функции (таблица истинности, упрощение, полиномы);
- проверить основные пользовательские сценарии GUI.

## Уровни тестирования

### Unit‑тесты (автоматические)

Расположены в `tests/unit/`. Покрывают ключевые модули backend.

Запуск:
```bash
pytest tests/unit/ -v
```

Все тесты стабильно проходят.

### Ручное тестирование GUI

Оформлено в виде методики тест‑кейсов (`tests/manual/test_cases.md`).  
Документ содержит 14 сценариев, покрывающих все шесть пунктов МУ.

Основные сценарии:
- добавление и соединение элементов,
- удаление, перемещение, отмена/повтор действий,
- таблица истинности всей схемы и по элементу с подсветкой,
- упрощение схемы при фиксированных входах (оценка и применение),
- полиномиальное представление,
- настройка параметров отображения,
- сохранение и загрузка XML,
- обработка некорректного XML.

### Интеграционные тесты (автоматические)

Расположены в `tests/integration/`. Проверяют совместную работу нескольких модулей:
модели, команд, XML‑сериализации и вычислительной логики.

**Покрываемые сценарии:**
- Полный workflow: создание схемы, вычисление таблицы истинности, сохранение в XML,
  загрузка обратно и проверка идентичности данных.
- Цепочки команд undo/redo с проверкой состояния связей после каждой операции.
- XML round‑trip: структура и логика схемы сохраняются.
- Обработка повреждённого XML.
- Упрощение схемы с фиксацией входов и проверкой корректности вычислений.
- Работа с большими схемами (цепочка из 10 входов и 9 AND‑элементов).
- Проверка, что повтор после новой команды недоступен (очистка redo‑стека).
- Сложная комбинационная схема (AND → XOR → OR) с проверкой после загрузки из XML.

Все тесты стабильно проходят вместе с unit‑тестами.

## Набор тестовых схем (фикстуры)

В `tests/fixtures/` подготовлены готовые XML‑файлы:

| Файл | Назначение |
|------|------------|
| `half_adder.xml` | Полусумматор (2 входа, XOR, AND, 2 выхода) — таблица истинности всей схемы и по элементу, сохранение/загрузка |
| `simple_and.xml` | 2 входа, AND, выход — упрощение при фиксированном входе |
| `invalid.xml` | Схема со ссылкой на несуществующий узел — проверка ошибки загрузки |
