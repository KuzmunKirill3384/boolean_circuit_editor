# Описание приложения

Приложение «Редактор булевых схем» представляет собой графическую среду для создания и анализа цифровых логических схем. Пользователь может добавлять на рабочую область элементы следующих типов:

- **IN** — вход схемы, источник логического сигнала (0 или 1)
- **OUT** — выход схемы, отображает результат
- **AND** — логическое И
- **OR** — логическое ИЛИ
- **XOR** — исключающее ИЛИ
- **EQUAL** — логическое равенство
- **CONST_0** / **CONST_1** — константные источники (используются при упрощении)

Элементы соединяются между собой проводами. Приложение проверяет корректность соединений: запрещается создавать циклы, подключать более одного источника к одному входному пину, использовать несуществующие узлы. Все операции редактирования поддерживают отмену (Undo) и повтор (Redo).

## Основные возможности

### 1. Редактирование схемы

- Добавление, удаление, перемещение элементов.
- Создание и удаление соединений между пинами.
- Undo/Redo для всех операций редактирования.

### 2. Таблица истинности

- **Для всей схемы**: отображает все `2^n` комбинаций входных сигналов и соответствующие значения на выходах (столбцы `IN_<id>` и `OUT_<id>`).
- **Для выбранного элемента**: показывает, как зависит значение конкретного узла от входов схемы; при этом все влияющие на него узлы подсвечиваются на схеме.

### 3. Упрощение схемы

Пользователь задаёт фиксированные значения (0 или 1) для одного или нескольких входов. Программа:

1. Заменяет зафиксированные входные узлы (IN) на константные источники (CONST_0 или CONST_1).
2. Выводит оценку — сколько элементов потенциально станет недостижимым с выходов схемы при каждом варианте фиксации.
3. По подтверждению пользователя применяет замену и удаляет недостижимые узлы.

Операция упрощения обратима через Undo.

### 4. Полиномиальное представление

Для любого элемента (или для всей схемы) выводится строковое выражение, отражающее булеву функцию данного узла в терминах входов схемы. Используются обозначения:

| Элемент | Символ |
|---------|--------|
| AND | `*` |
| OR | `+` |
| XOR | `⊕` |
| EQUAL | `=` |
| IN (вход с id N) | `xN` |
| CONST_0 | `0` |
| CONST_1 | `1` |

Пример для схемы с двумя входами и XOR: `(x0 ⊕ x1)`.

### 5. Настройки отображения

Возможность изменять цвета каждого типа элементов, цвет линий соединений, цвет фона рабочей области, размеры узлов и шрифт подписей. Настройки сохраняются между сеансами работы через `QSettings`.

### 6. Сохранение и загрузка

Схема сохраняется в XML-файл, включая идентификаторы, типы и координаты всех узлов, а также все связи с указанием пинов. Загрузка ранее сохранённой схемы позволяет продолжить редактирование. Формат описан в разделе 5.
