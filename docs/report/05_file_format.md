# Формат файла схемы (XML)

Спецификацию формата ведёт **Боос Д. А.** в согласовании с **Кузьминым К. В.**. Этот документ фиксирует актуальный XML-формат хранения схемы, соответствующий реализации в `backend/io/xml_builder.py`.

## Назначение

XML-файл хранит:

- состав схемы (тип и идентификатор каждого элемента);
- координаты элементов на рабочей области;
- связи между выходами и входами с указанием номеров пинов.

Формат должен быть:

- человекочитаемым;
- простым для реализации через Builder;
- пригодным для ручного редактирования и отладки.

## Общая структура

Корневой элемент:

```xml
<circuit>
  <nodes />
  <connections />
</circuit>
```

Обязательные секции:

- `nodes` — все узлы схемы;
- `connections` — связи между узлами с указанием пинов.

## Корневой элемент

Корневой тег: `circuit`

Атрибуты на текущий момент не используются (версия и метаданные не сохраняются).

## Секция `nodes`

Каждый элемент описывается отдельным тегом `node`.

Пример:

```xml
<nodes>
  <node id="0" type="IN" x="40.0" y="120.0" />
  <node id="1" type="AND" x="200.0" y="170.0" />
  <node id="2" type="OUT" x="360.0" y="170.0" />
</nodes>
```

Обязательные атрибуты узла:

- `id` — уникальный целочисленный идентификатор в пределах схемы;
- `type` — тип элемента;
- `x` — координата по горизонтали (вещественное число, пиксели);
- `y` — координата по вертикали (вещественное число, пиксели).

Допустимые типы:

- `IN`
- `OUT`
- `AND`
- `OR`
- `XOR`
- `EQUAL`
- `CONST_0`
- `CONST_1`

Правила:

- `id` не должен повторяться;
- `type` должен принадлежать поддерживаемому списку;
- для `IN` количество входов равно 0, выходов — 1 (определяется программой);
- для `OUT` количество входов равно 1, выходов — 0;
- для логических элементов (`AND`, `OR`, `XOR`, `EQUAL`) по два входа и один выход;
- `CONST_0` и `CONST_1` не имеют входов, один выход (константные источники).

## Секция `connections`

Каждая связь описывается тегом `connection`.

Пример:

```xml
<connections>
  <connection out_node_id="0" out_pin="0" in_node_id="1" in_pin="0" />
  <connection out_node_id="1" out_pin="0" in_node_id="2" in_pin="0" />
</connections>
```

Обязательные атрибуты:

- `out_node_id` — идентификатор узла-источника;
- `out_pin` — индекс выходного пина источника (целое число, начиная с 0);
- `in_node_id` — идентификатор узла-приёмника;
- `in_pin` — индекс входного пина приёмника (целое число, начиная с 0).

Правила валидации:

- источник и приёмник должны ссылаться на существующие элементы;
- индексы пинов должны находиться в допустимых диапазонах (у `IN` один выходной пин 0, у `OUT` один входной пин 0, у логических элементов два входных 0 и 1, один выходной 0);
- один входной пин не должен получать более одной связи;
- связь не должна создавать цикл;
- прямое соединение элемента с самим собой запрещено, если оно порождает цикл.

## Что не хранится в XML схемы

- Глобальные настройки приложения (цвета, шрифты, размеры) хранятся отдельно в `QSettings`;
- история Undo/Redo;
- метаданные (название, автор)

## Полный пример

```xml
<?xml version="1.0" encoding="UTF-8"?>
<circuit>
  <nodes>
    <node id="0" type="IN" x="40.0" y="100.0" />
    <node id="1" type="IN" x="40.0" y="200.0" />
    <node id="2" type="AND" x="200.0" y="150.0" />
    <node id="3" type="OUT" x="360.0" y="150.0" />
  </nodes>
  <connections>
    <connection out_node_id="0" out_pin="0" in_node_id="2" in_pin="0" />
    <connection out_node_id="1" out_pin="0" in_node_id="2" in_pin="1" />
    <connection out_node_id="2" out_pin="0" in_node_id="3" in_pin="0" />
  </connections>
</circuit>
```

## Ошибки формата, которые должен ловить загрузчик

- отсутствует корневой тег `circuit`;
- нет секции `nodes` (секция `connections` может быть пустой);
- повторяются `id` узлов;
- связь ссылается на несуществующий узел;
- тип узла не поддерживается;
- индексы пинов выходят за допустимый диапазон;
- схема содержит цикл;
- на один входной пин подано более одного соединения.

## Примечания по реализации

- Кодировка файла: `UTF-8`.
- Для работы используется `xml.etree.ElementTree`.
- Загрузчик (`import_from_xml`) при обнаружении некорректной связи выбрасывает `ValueError` с описанием причины.
