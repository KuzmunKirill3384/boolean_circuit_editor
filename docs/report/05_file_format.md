# Формат файла схемы (XML)

Документ фиксирует актуальный XML-формат, соответствующий реализации в `backend/io/xml_builder.py`.

## Назначение

XML-файл хранит:

- состав схемы (тип и идентификатор каждого элемента);
- координаты элементов на рабочей области;
- связи между выходами и входами с указанием номеров пинов.

Формат является:

- человекочитаемым;
- простым для реализации через Builder;
- пригодным для ручного редактирования и отладки.

## Общая структура

Корневой элемент — `<circuit>`, содержит две обязательные секции:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<circuit>
  <nodes />
  <connections />
</circuit>
```

## Секция `nodes`

Каждый элемент схемы описывается тегом `<node>`.

```xml
<nodes>
  <node id="0" type="IN"  x="40.0"  y="100.0" />
  <node id="1" type="IN"  x="40.0"  y="200.0" />
  <node id="2" type="AND" x="200.0" y="150.0" />
  <node id="3" type="OUT" x="360.0" y="150.0" />
</nodes>
```

Обязательные атрибуты:

| Атрибут | Тип | Описание |
|---------|-----|----------|
| `id` | целое | Уникальный идентификатор узла в пределах схемы |
| `type` | строка | Тип элемента (см. таблицу ниже) |
| `x` | вещественное | Координата по горизонтали (пиксели) |
| `y` | вещественное | Координата по вертикали (пиксели) |

Допустимые типы и их пины:

| Тип | Входов | Выходов | Описание |
|-----|--------|---------|----------|
| `IN` | 0 | 1 | Вход схемы |
| `OUT` | 1 | 0 | Выход схемы |
| `AND` | 2 | 1 | Логическое И |
| `OR` | 2 | 1 | Логическое ИЛИ |
| `XOR` | 2 | 1 | Исключающее ИЛИ |
| `EQUAL` | 2 | 1 | Логическое равенство |
| `CONST_0` | 0 | 1 | Константный ноль |
| `CONST_1` | 0 | 1 | Константная единица |

## Секция `connections`

Каждая связь описывается тегом `<connection>`.

```xml
<connections>
  <connection out_node_id="0" out_pin="0" in_node_id="2" in_pin="0" />
  <connection out_node_id="1" out_pin="0" in_node_id="2" in_pin="1" />
  <connection out_node_id="2" out_pin="0" in_node_id="3" in_pin="0" />
</connections>
```

Обязательные атрибуты:

| Атрибут | Тип | Описание |
|---------|-----|----------|
| `out_node_id` | целое | Идентификатор узла-источника |
| `out_pin` | целое | Индекс выходного пина источника (от 0) |
| `in_node_id` | целое | Идентификатор узла-приёмника |
| `in_pin` | целое | Индекс входного пина приёмника (от 0) |

## Правила валидации

Загрузчик (`import_from_xml`) проверяет и отклоняет файлы, если:

- отсутствует корневой тег `<circuit>`;
- отсутствует секция `<nodes>`;
- повторяются `id` узлов;
- связь ссылается на несуществующий узел (`out_node_id` или `in_node_id` не найден);
- тип узла не входит в список допустимых;
- индекс пина выходит за допустимый диапазон;
- один входной пин получает более одной связи;
- связи образуют цикл в графе схемы.

При обнаружении некорректных данных выбрасывается `ValueError` с описанием причины.

## Что не хранится в XML

- Настройки отображения (цвета, шрифты, размеры) — хранятся в `QSettings`.
- История Undo/Redo.
- Метаданные (название, автор, дата).

## Полный пример

```xml
<?xml version="1.0" encoding="UTF-8"?>
<circuit>
  <nodes>
    <node id="0" type="IN"  x="40.0"  y="100.0" />
    <node id="1" type="IN"  x="40.0"  y="200.0" />
    <node id="2" type="AND" x="200.0" y="150.0" />
    <node id="3" type="OUT" x="360.0" y="150.0" />
  </nodes>
  <connections>
    <connection out_node_id="0" out_pin="0" in_node_id="2" in_pin="0" />
    <connection out_node_id="1" out_pin="0" in_node_id="2" in_pin="1" />
    <connection out_node_id="2" out_pin="0" in_node_id="3" in_pin="0" />
  </connections>
</circuit>
```

## Примечания по реализации

- Кодировка файла: `UTF-8`.
- Используется `xml.etree.ElementTree` из стандартной библиотеки Python.
- Координаты сохраняются как вещественные числа с плавающей точкой.
- Порядок узлов в секции `<nodes>` соответствует порядку их добавления в схему (по возрастанию `id`).
