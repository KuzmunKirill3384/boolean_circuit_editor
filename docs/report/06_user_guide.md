# Руководство оператора

## Запуск приложения

1. Убедитесь, что установлен Python 3.10 или выше.
2. Откройте терминал (командную строку) и перейдите в корневую папку проекта.
3. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv .venv
   source .venv/bin/activate   # Linux/macOS
   .venv\Scripts\activate      # Windows
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустите приложение:
   ```bash
   python run.py
   ```

## Рабочее окно

Главное окно состоит из следующих элементов:

- **Меню** (строка вверху): Файл, Правка, Вид.
- **Панель инструментов**: кнопки для добавления элементов и переключения режимов.
- **Рабочая область** (центральная часть): здесь располагается схема.
- **Боковая панель** «Таблица истинности» (по умолчанию открыта справа).

## Основные действия

### Добавление элемента
1. На панели инструментов нажмите кнопку с названием нужного элемента: **IN**, **OUT**, **AND**, **OR**, **XOR**, **EQUAL**.
2. Кликните в любом свободном месте рабочей области – элемент появится в выбранной точке.

### Соединение элементов
1. Нажмите кнопку **Связь** на панели инструментов.
2. Кликните по выходному пину первого элемента (маленький кружок справа).
3. Кликните по входному пину второго элемента (кружок слева). Если соединение допустимо, появится линия связи.
   - Нельзя соединить выход с выходом или вход с входом.
   - Нельзя подключать больше одной связи к одному входному пину.
   - Нельзя создавать циклы.

### Отключение связи
1. Нажмите кнопку **Отключить**.
2. Кликните по выходному пину источника, затем по входному пину приёмника – связь удалится.

### Перемещение элемента
Перетащите элемент мышью. Связи автоматически перерисуются.

### Удаление элемента
1. Выделите элемент (кликните на нём).
2. Нажмите клавишу **Delete** или кнопку «Удалить» на панели инструментов. Элемент и все его связи будут удалены.

### Отмена и повтор действий
- Используйте меню **Правка → Отмена** (или **Ctrl+Z**).
- Используйте меню **Правка → Повтор** (или **Ctrl+Y**).

## Таблица истинности

Боковая панель «Таблица истинности» показывает результаты для всей схемы.

- Чтобы обновить таблицу, нажмите кнопку **Обновить**.
- Таблица содержит столбцы для всех входов (`IN_...`) и всех выходов (`OUT_...`). Строки перебирают все возможные комбинации значений на входах.
- Если схема не содержит входов и/или выходов или имеет структурные ошибки, панель выведет сообщение.

*Примечание: режим «по элементу» с подсветкой влияющих узлов реализован в вычислительном ядре, его интерфейс появится в ближайшем обновлении.*

## Упрощение схемы

Функция упрощения позволяет сократить схему, зафиксировав значения одного или нескольких входов.

1. Выберите в меню **Вид → Упрощение схемы**.
2. В открывшемся окне для каждого входа выберите одно из значений: **Не установлено**, **0** или **1**.
   - Сразу после выбора вы увидите, сколько элементов можно удалить, если зафиксировать этот вход (например, `0→3, 1→2`).
3. В блоке «Итого при упрощении» показано общее количество элементов в текущей схеме и сколько из них будет удалено при применении выбранных значений.
4. Нажмите кнопку **OK** (или «Применить») – схема будет перестроена. Операцию можно отменить обычным способом (через **Правка → Отмена**).

## Полиномиальное представление

Для каждого логического элемента можно получить текстовое выражение, отражающее его функцию.

1. Выберите в меню **Вид → Полиномиальное представление**.
2. В левой части окна появится дерево элементов, сгруппированных по типам (`IN`, `AND`, `OR` и т.д.).
3. Кликните на конкретный элемент – справа отобразится его полином в виде:
   ```
   f_<id> = выражение
   ```
   где используются следующие обозначения:
   - `x<id>` – вход с указанным идентификатором,
   - `*` – AND,
   - `+` – OR,
   - `⊕` – XOR,
   - `=` – EQUAL.
4. Чтобы закрыть окно, нажмите кнопку **Close**.

## Настройки отображения

1. Меню **Вид → Настройки**.
2. В открывшемся диалоге можно изменить:
   - Цвет каждого типа элементов (AND, OR, XOR, EQUAL, IN, OUT, CONST_0, CONST_1).
   - Цвет линий соединений.
   - Цвет фона рабочей области.
   - Ширину и высоту узлов.
   - Шрифт подписей.
3. Нажмите **Применить**, чтобы увидеть изменения без закрытия окна, или **OK** для сохранения и закрытия.

Настройки сохраняются автоматически в системе и будут использованы при следующем запуске.

## Сохранение и загрузка схемы

- **Сохранить**: меню **Файл → Сохранить**. Выберите имя файла (расширение `.xml`). Схема будет сохранена в XML-формате, описанном в документации.
- **Открыть**: меню **Файл → Открыть**. Выберите ранее сохранённый XML-файл – схема загрузится со всеми элементами и связями.

## Подсказка по управлению

При нажатии кнопки **Подсказка** на панели инструментов открывается окно с краткой инструкцией:

- **Добавление:** выберите тип элемента и кликните по сцене.
- **Связь:** нажмите «Связь», выберите выходной пин, затем входной.
- **Отключить:** нажмите «Отключить» и кликните по линии связи или по паре пинов.
- **Клавиатура:** стрелки двигают поле, `+`/`-` меняют масштаб, `Delete`/`Backspace` удаляет выбранные блоки.

## Пример: создание полусумматора

1. Добавьте два входа **IN**. Расположите их слева.
2. Добавьте элемент **XOR** (сумма) и **AND** (перенос).
3. Добавьте два выхода **OUT** (один для суммы, один для переноса).
4. Соедините:
   - Первый вход → вход 0 XOR и вход 0 AND.
   - Второй вход → вход 1 XOR и вход 1 AND.
   - Выход XOR → первый выход.
   - Выход AND → второй выход.
5. Нажмите **Показать таблицу** (или вкладка «Таблица истинности» уже открыта). Вы увидите стандартную таблицу истинности полусумматора.
