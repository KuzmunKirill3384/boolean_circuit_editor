### Главный разрыв «сейчас → идеал»

Не хватает **полировки UX**, **синхронизации документации с кодом**, **расширенного тестирования**, **полного UML-пакета** и **честного закрытия scope** по функциям, которые в UI ещё не доведены до ТЗ.

## 2. Критерий «идеала» (Definition of Done)

Проект считается доведённым до идеала, когда одновременно выполнено:

1. **ТЗ закрыто в UI** — все обязательные пользовательские сценарии доступны без обходных путей и «это есть только в backend».
2. **Пять паттернов** отражены в коде, UML и тексте отчёта; формулировки не противоречат реализации.
3. **README и docs/** описывают фактическое поведение (без «будущий код», «интерфейс дорабатывается»).
4. **Тесты:** ≥20 backend unit + smoke GUI + зафиксированный отчёт прогона.
5. **Защита:** class + sequence диаграммы, скриншоты, сценарий 5–7 мин, блок Q&A.
6. **Демо стабильно** проходит за 4–6 минут без падений и «забытых» шагов.

## 4. Матрица «требование ТЗ → что проверить»

| Требование | Где в коде | Как доказать на защите |
|------------|------------|-------------------------|
| Редактирование | `AppController` + commands | Живое демо на canvas |
| Undo/Redo | `CommandHistory` | 3 действия → 2× undo → redo |
| Валидация | `Circuit.validate_*` | Попытка цикла / двойного входа |

| TT элемента | `get_truth_table_for_node` | Режим «По элементу» |
| Упрощение | `simplify` | Диалог + меньше узлов на canvas |
| Прогноз | `get_removable_count_per_input` | Колонки if_0 / if_1 |
| Полиномы | `get_polynomials` | Диалог + копирование |
| XML | `xml_builder` | Save → Load |
| Composite | `model/*` | Показать `accept` / `create_node` |
| Visitor | `visitor/*` | `NodeRolesVisitor` в TT |
| Command | `history.py` | undo после remove |
| Factory | `factory.py` | Нет `AddNodeCommand(` в контроллере |
