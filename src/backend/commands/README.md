# Backend Commands

- `history.py` — команды и `CommandHistory` (Command)
- `factory.py` — `CommandFactory` (Factory): единая точка создания команд

Планируемые сущности:

- базовая команда;
- команды добавления и удаления элементов;
- команды создания и удаления связей;
- команды перемещения;
- история undo/redo;
- фабрика команд.
