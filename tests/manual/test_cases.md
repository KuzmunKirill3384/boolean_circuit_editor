# Методика ручного тестирования редактора булевых схем


| ID | Название | Пункт МУ | Предусловие | Шаги | Ожидаемый результат |
|----|----------|----------|-------------|------|----------------------|
| TC-01 | Добавление элемента | 1 | Открыто главное окно, пустая схема | 1. Нажать кнопку «AND» на панели инструментов. 2. Кликнуть в произвольном месте рабочей области. | Появился элемент с символом ∧. |
| TC-02 | Соединение элементов | 1 | На схеме есть два входа (IN) и один AND | 1. Нажать кнопку «Связь». 2. Кликнуть по выходному пину первого входа (кружок справа). 3. Кликнуть по первому входному пину AND (кружок слева сверху). | Появилась линия связи между элементами. |
| TC-03 | Запрет цикла | 1 | Схема из двух AND, один соединён ко второму | 1. Попытаться соединить выход второго AND со входом первого. | Соединение не создаётся, появляется сообщение об ошибке «Connection would create a cycle». |
| TC-04 | Удаление элемента | 1 | На схеме есть любой элемент | 1. Кликнуть по элементу (он выделится). 2. Нажать клавишу Delete. | Элемент и все его связи исчезли. |
| TC-05 | Отмена (Undo) | 1 | Только что удалили элемент (TC-04) | 1. Выбрать меню «Правка → Отмена» или нажать Ctrl+Z. | Элемент и его связи восстановились. |
| TC-06 | Повтор (Redo) | 1 | Только что отменили удаление (TC-05) | 1. Выбрать меню «Правка → Повтор» или нажать Ctrl+Y. | Элемент снова удалён. |
| TC-07 | Перемещение элемента с отменой | 1 | На схеме есть элемент AND | 1. Перетащить AND мышью в другое место. 2. Нажать Ctrl+Z (или «Правка → Отмена»). | Элемент вернулся на исходную позицию. |
| TC-08 | Таблица истинности всей схемы | 2 | Загружена схема полусумматора (файл `half_adder.xml` из папки `tests/fixtures`) | 1. Открыть боковую панель «Таблица истинности». 2. Нажать кнопку «Обновить». | Отображается таблица с 4 строками (00,01,10,11) и правильными значениями на выходах SUM и CARRY. |
| TC-09 | Таблица истинности по элементу с подсветкой | 2 | Та же схема полусумматора | 1. В панели «Таблица истинности» включить режим «По элементу». 2. Кликнуть по XOR на сцене. | В таблице отображаются только входы, влияющие на XOR, и значение XOR. Все влияющие узлы (оба IN) подсвечены оранжевым. |
| TC-10 | Упрощение схемы с оценкой | 3 | Схема из двух входов и AND (файл `simple_and.xml` из папки `tests/fixtures`) | 1. Выбрать меню «Вид → Упрощение схемы». 2. Для первого входа установить значение 0. 3. Посмотреть оценку «Будет удалено» (должно быть >0). 4. Нажать «ОК». | Показано количество потенциально упрощаемых элементов. После нажатия ОК вход IN преобразован в элемент CONST_0 (или CONST_1), его значок на схеме изменился. Элементы AND и второй вход остаются на схеме — они нужны для корректного вычисления через константу. Выход по-прежнему проходит через AND, но результат всегда равен 0 (т.к. один вход зафиксирован в 0). Операцию можно отменить (Ctrl+Z) — элемент IN возвращается. |
| TC-11 | Полиномиальное представление | 4 | Схема с XOR (можно использовать полусумматор) | 1. Выбрать меню «Вид → Полиномиальное представление». 2. В дереве раскрыть группу XOR, кликнуть по элементу. | В правой части отображается полином вида `f_X = (x0 ⊕ x1)`. |
| TC-12 | Настройка цвета и размера элементов | 5 | Открыто главное окно, есть любой элемент | 1. Меню «Вид → Настройки». 2. Изменить цвет AND на зелёный, цвет линий на синий, фон на светло-серый, увеличить ширину до 120, выбрать шрифт «Courier». 3. Нажать «Применить» и «ОК». | Цвета, размер и шрифт элемента изменились согласно настройкам. |
| TC-13 | Сохранение в XML и загрузка | 6 | Схема полусумматора (можно загрузить из `half_adder.xml`) | 1. Выбрать меню «Файл → Сохранить». 2. Указать имя файла и сохранить. 3. Выбрать меню «Файл → Открыть» и загрузить этот файл. | Схема полностью восстановлена: все элементы и связи на прежних местах, таблица истинности идентична. |
| TC-14 | Загрузка некорректного XML | 6 | Файл с ошибкой (например, `invalid.xml` из `tests/fixtures`) | 1. Выбрать меню «Файл → Открыть» и указать повреждённый файл. | Появляется сообщение об ошибке загрузки, схема не меняется. |

---

## Примечания к демонстрации
- Тест-кейсы **TC-08, TC-09, TC-13** удобно использовать готовую схему `tests/fixtures/half_adder.xml`
- Для **TC-10** удобно использовать готовую схему `tests/fixtures/simple_and.xml`
- Для **TC-14** используйте `tests/fixtures/invalid.xml`, который содержит ссылку на несуществующий узел

Все сценарии проверены и воспроизводятся в текущей версии приложения.
